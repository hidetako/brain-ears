# Binaural Player

左右の耳に別々の音を流す Windows 用プレーヤーです。少しだけ周波数の違う純音(バイノーラルビート)のほか、
左右それぞれに別の音声ファイルを登録して再生できます。
ヘッドホンまたはイヤホンで使用してください。

## 機能

| 項目 | 範囲 | 内容 |
|---|---|---|
| 音源 | 純音 / 音声ファイル | 音声ファイルは左ch 用・右ch 用を別々に登録 |
| 音量(左右別) | 0〜100 % | 左右それぞれ独立に設定。「耳に固定」「チャンネルに固定」を選択 |
| 音量(両方) | 0〜100 % | 左右の比を保ったまま、両方を同じ割合で上げ下げ |
| 左右の周波数差(純音) | 0.5〜20 Hz(0.1 刻み) | 左耳 = 基準音、右耳 = 基準音 + 差。ボタンで 1〜20 Hz の決まった値へ一度に移れる |
| 基準音(純音) | 40〜400 Hz | 既定 200 Hz。ボタンで 100〜400 Hz の決まった値へ一度に移れる |
| 左右入れ替え | 0.1〜5 秒(0.1 刻み) | 指定間隔ごとに左右の音を入れ替える(オン/オフ可) |

- 音量の効かせ方は 2 通りから選べます。
  - **耳に固定**: 左右を入れ替えても各耳の音量は変わりません。左を小さくしていれば、入れ替え中も左耳は小さいままです(左右の聞こえ方の差の補正向け)。
  - **チャンネルに固定**: 音量は音源(左ch・右ch)に付き、入れ替えると音量も音と一緒に反対の耳へ移ります(左右に別の音源を入れる場合向け)。
- 純音の入れ替えは、音を混ぜ替えるのではなく各耳の音の周波数を最大 30 ミリ秒かけて滑らかに移します。波形がつながったままなので、入れ替えの瞬間にノイズが出ません。
- 設定は自動保存され、次回起動時に復元されます。

### 音声ファイル

- 「音源」で「音声ファイル」を選び、左ch・右ch それぞれの「選択」からファイルを登録します。片方だけでも再生できます。
- 対応形式: mp3 / wav / m4a / aac / ogg / opus / flac / webm。ステレオのファイルはモノラルに混ぜて、そのチャンネルの耳へ流します。
- ファイルは繰り返し再生されます。左右のファイルの長さが違う場合は、それぞれ独立に繰り返します。
- 「停止」は一時停止で、次の「再生」で続きから鳴ります。「先頭に戻す」で最初に戻ります。
- 音量 100 % でファイルの元の音量になります。
- 左右入れ替えは 2 つのファイルを最大 50 ミリ秒でクロスフェードします。
- 登録したファイルの場所は記憶され、次回起動時に読み直します。ファイルを移動・削除した場合は登録が外れます。

## インストール

[Releases](https://github.com/hidetako/brain-ears/releases/latest) から
`Binaural-Player-Setup-x.y.z.exe` をダウンロードして実行します。

コード署名をしていないため、初回実行時に Windows SmartScreen の警告が出ます。
「詳細情報」→「実行」で進めてください。

## 自動更新

起動のたびに GitHub Releases を確認し、新しい版があれば裏でダウンロードします。
完了すると「今すぐ再起動」か「あとで(終了時に更新)」を選べます。状況は画面右下に表示されます。

## 新しい版の出し方

`package.json` の `version` を上げて main に push するだけです。

```bash
npm version patch --no-git-tag-version
```

```bash
git commit -am "Release 1.0.1"
```

```bash
git push origin main
```

main への push をきっかけに GitHub Actions が動き、その version の Release がまだ無ければ
Windows 上でインストーラーをビルドして Release(タグ `v1.0.1` など)として公開します。
既存ユーザーは次回起動時に自動で更新されます。version を変えていない push では何も公開されません。

自動更新は公開(Public)リポジトリの Release を前提にしています。Private のままでは更新を取得できません。

## 開発

```bash
npm install
```

```bash
npm start
```

```bash
npm test
```

`npm test` は Chromium 上で実際に音声エンジンを動かし、純音と音声ファイルの両方について
左右チャンネルの周波数・音量・入れ替えを測定します(Playwright が必要)。

```bash
npm run test:app
```

`npm run test:app` は実際のアプリを起動し、音声ファイルの登録が再起動後も復元されて鳴ることを確認します。

## 構成

- `src/engine.js` — Web Audio API による音声エンジン
- `src/renderer.js` / `index.html` / `style.css` — 画面
- `src/main.js` — Electron 本体と自動更新(electron-updater)
- `.github/workflows/release.yml` — インストーラーのビルドと公開
